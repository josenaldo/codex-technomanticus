# The AI Vampire — Steve Yegge

## TL;DR

Steve Yegge argumenta que a IA (especificamente Claude Code com Opus 4.5/4.6) realmente entrega o ganho de 10x, mas funciona como um "vampiro de energia" que drena os desenvolvedores: a programação agêntica vicia como caça-níquel, o trabalho fica acelerado e exaustivo, e as empresas tendem a capturar todo o valor gerado. Sua solução é a fórmula `$/hr` — você não controla o numerador (salário), mas controla o denominador (horas) — e propõe uma jornada de 3 a 4 horas como o novo padrão sustentável.

## Pontos-chave

- O ganho de 10x com IA é real depois que se aprende a usá-la; Yegge marca 24/nov/2025 como o "event horizon" do coding agêntico, com Opus 4.5/4.6 + Claude Code.
- Metáfora central: a IA é um "vampiro de energia" (estilo Colin Robinson, de *What We Do in the Shadows*) — estar "na mesma sala" que a IA drena as pessoas.
- Problema de captura de valor: trabalhar 8h a 10x faz o empregador capturar 100% do valor (e você se esgota); trabalhar 1h faz você capturar o valor, mas a empresa quebra. O equilíbrio precisa ficar no meio.
- A programação agêntica vicia como caça-níquel (dopamina/adrenalina a cada prompt); early adopters extremos (ele próprio, contas múltiplas de Claude, Jeffrey Emanuel com 22 contas a US$ 4.400/mês) criam "padrões de beleza irreais" para o desenvolvedor médio.
- Startups AI-native e o sistema de VC aceleram a extração/drenagem das pessoas em busca de ideias banais; "Build is the New Buy" vai matar a maioria desses SaaS.
- Solução `$/hr`: você não controla o numerador (salário), mas controla o denominador (horas trabalhadas); coletivamente, os funcionários têm todo o poder de empurrar o "dial" para baixo.
- Proposta concreta: a nova jornada deveria ser de 3 a 4 horas de trabalho real com IA; assuma que a exaustão é a norma, "touch grass" todo dia e faça algo sem IA.

> [!info] O que é "Gas Town"?
> No texto, "Gas Town" aparece duas vezes — "their whole company has 3+ Claude Pro/Max accounts for Gas Town" e "with Gas Town I have mastered the illusion of knowing what I'm doing". É o sistema open-source de orquestração multi-agente criado pelo próprio Steve Yegge (também grafado *Gastown* / *Gas City*). Roda de 20 a 30 instâncias do Claude Code em paralelo, coordenadas — Yegge o descreve como "Kubernetes para agentes de codificação": um agente "prefeito" (*mayor*) gerencia uma "cidade" de agentes coders, reviewers e supervisores. Introduz os *beads*, um issue tracker leve que funciona como memória externa compartilhada entre os agentes. Exige supervisão manual intensa e queima créditos de API rápido (relatos de ~US$ 100/hora).
