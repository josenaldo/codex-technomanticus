# Revenge of the junior developer — Steve Yegge

## TL;DR

Yegge fecha sua trilogia (Junior → Stubborn → Revenge) declarando que chat coding (CHOP) já está sendo eclipsado por coding agents, e que em seis ondas sobrepostas a programação vai passar por agent clusters (H2 2025) e agent fleets (2026). A reviravolta: juniores adotaram IA mais rápido que sêniores e custam menos; quando cada dev passa a gastar US$ 50k-100k/ano em tokens, são os juniores que vão sobrar no corte.

## Pontos-chave

- Yegge propõe seis ondas sobrepostas de programação: tradicional (2022), completions (2023), chat-based (2024), coding agents (H1 2025), agent clusters (H2 2025), agent fleets (2026). Cada nova onda é conservadoramente ~5x mais produtiva que a anterior.
- "Vibe coding" (termo cunhado por Karpathy em fevereiro/2025) não é uma modalidade, é o nome guarda-chuva pra qualquer cenário em que a IA escreve o código — cobre chat, agents, clusters e fleets.
- Coding agents (tipo Aider, Claude Code) já fazem o ciclo todo de um ticket: leem o JIRA, acessam ferramentas, escrevem código, escrevem testes, rodam testes e iteram até passar; o humano só desbloqueia, autoriza ferramentas e supervisiona.
- Matemática brutal pra CIO: cada agent gasta US$ 10-12/hora em tokens; rodar 5 agents em paralelo por dev = ~US$ 100k/ano de opex de LLM por dev. Empresas que não orçaram isso pra 2026 vão precisar cortar pessoal pra liberar opex.
- Agent fleets (2026) trazem agentes supervisores que orquestram pods de coding agents; o dev individual vira gerente de segundo nível de uma "fazenda de agentes" (FY26 Org Chart).
- Agent clusters vão finalmente migrar dev pro cloud — desktop pessoal não suporta rodar dezenas de agents em paralelo, então a história longa de "IDE no cloud" finalmente acontece.
- A reviravolta: juniores adotaram IA mais rápido que sêniores (que estão presos ao status quo, equiparando "aprender o novo" com "perder o emprego"). Como juniores aceleram com agents e custam menos, são eles que ficam quando o corte vier.

## Citações

> "Vibe coding simply means never writing code again."

> "Each successive modality wave, beginning with chat, is conservatively about 5x as productive as the previous wave."

> "Software development is now a pay-to-play bullet train. If you can't afford a ticket, you risk getting red-shifted away from the pack."

> "It's not AI's job to prove it's better than you. It's *your* job to get better using AI."

> "The new job of 'software engineer,' by the end of this year, will involve little direct coding, and a *lot* of agent babysitting."
