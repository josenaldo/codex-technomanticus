# Sendas

> [!abstract] TL;DR
> Caminhos transversais pelos domínios, calibrados por papel ou stack — curadorias que cortam várias trilhas pra montar uma jornada coerente pra um perfil específico.

Esta pasta agrupa as Sendas: percursos curados que atravessam os domínios pra fazer sentido pra um papel ou stack específico (Frontend, Backend, Fullstack, IA, etc.). Cada senda é uma seleção transversal de notas de várias trilhas, ordenada pra alguém que está se preparando ou se aprofundando naquela direção. Diferente das trilhas (que são verticais por tema), as sendas são horizontais por perfil — o mesmo conhecimento aparece organizado por intenção de uso.
