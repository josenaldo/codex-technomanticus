# Event Storming

> [!abstract] TL;DR
> Event Storming — técnica colaborativa de design orientado a domínio (DDD) que usa post-its coloridos para mapear eventos de negócio, comandos, agregados e bounded contexts.

Event Storming junta pessoas de produto, negócio e engenharia em torno de uma parede (ou board digital) para reconstruir o fluxo de eventos de um domínio. É um instrumento de descoberta antes de virar código: revela ambiguidades de linguagem, gargalos de processo e fronteiras naturais entre contextos. Esta estante traz a nota-mãe com a técnica e exemplos aplicados.
