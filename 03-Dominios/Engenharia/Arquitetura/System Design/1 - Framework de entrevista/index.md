# Framework de entrevista — System Design

O processo antes do conteúdo. Uma entrevista de system design não pede *a resposta certa* — pede que você **estruture o problema**, **estime a escala** e **explicite trade-offs** em voz alta. Este sub-galho (fase **Iniciado**) dá o roteiro dos 45-60 min para você nunca ficar olhando o quadro em branco.
