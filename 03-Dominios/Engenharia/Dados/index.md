# Dados

> [!abstract] TL;DR
> A **engenharia de dados em escala** — o que vem depois de "saber SQL": modelagem dimensional, data warehousing, pipelines/ETL-ELT, streaming, data lakes/lakehouse, qualidade e governança. O *como construir sistemas de dados*, neutro de ferramenta.

Domínio em formação. Trata da engenharia de dados como disciplina, distinta da **teoria de banco de dados** (modelo relacional, ACID, normalização, índices) que vive inteira em [[03-Dominios/Ciência/Banco de Dados/index|Banco de Dados]], na camada de Ciência. Aqui ficam as decisões de construção: como modelar para analytics, como mover dados entre sistemas, como garantir consistência e qualidade em pipelines.
