# Certificação (PCEP/PCAP)

> [!abstract] TL;DR
> Galho 19, ÚLTIMO galho da trilha Python: guia de estudo mapeado às certificações da Python Institute — **PCEP-30-02** (Certified Entry-Level Python Programmer, 4 blocos) e **PCAP-31-03** (Certified Associate in Python Programming, 5 blocos, o alvo principal pra quem já programa). Cada bloco oficial do syllabus é mapeado às notas já escritas nos Galhos 1-6 (núcleo da linguagem) — este galho não reensina Python, ele organiza o que já foi ensinado no formato e na ênfase que o exame cobra, mais os padrões de questão e as armadilhas específicas da prova. Fecha com um simulado comentado. Fase Magus; 8 notas.

## Sobre este galho

Este é o último galho da trilha. Ele pressupõe TODO o núcleo da linguagem (Galhos 1-6) e reorganiza esse conteúdo sob a lente de duas certificações reais da Python Institute — não ensina Python do zero, é um guia de revisão dirigido ao formato de prova (múltipla escolha, "o que este código imprime", pegadinhas de sintaxe, sob tempo).

**Fronteiras anti-duplicação:** todo o conteúdo TÉCNICO de Python (sintaxe, tipos, OOP, exceções, módulos) já está nos Galhos 1-6 — aqui só mapeamos e revisamos, sem reescrever explicações já feitas. O que é genuinamente novo aqui: o formato do exame, os pesos de cada bloco oficial, os padrões de pegadinha da Python Institute, e a estratégia de prova.

**Fontes oficiais consultadas (pesquisa 2026-07-12):** PCEP-30-02 syllabus (pythoninstitute.org/pcep-exam-syllabus) e PCAP-31-03 syllabus (pythoninstitute.org/pcap-exam-syllabus) — ambos com status "Live & Active" em 2026, sem indicação de nova versão em preparação.
