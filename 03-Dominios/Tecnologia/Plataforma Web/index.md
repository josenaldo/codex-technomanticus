# Plataforma Web

> [!abstract] TL;DR
> As APIs e capacidades do **navegador e do ambiente web** que independem de framework — comunicação HTTP no cliente (fetch/Axios), debugging, e (futuramente) as Web APIs (storage, workers, eventos). O *como o navegador funciona pra quem programa em cima dele*.

Domínio em formação. Reúne o que é da **plataforma web** em si — não da linguagem JavaScript nem de um framework específico. A fundamentação conceitual de rede/HTTP vive em [[03-Dominios/Ciência/Redes e Protocolos/index|Redes e Protocolos]]; aqui ficam as APIs concretas que o cliente usa.
