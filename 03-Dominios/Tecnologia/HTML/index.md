# HTML

> [!abstract] TL;DR
> A linguagem de **marcação de significado** da web. Usar o elemento certo — não o `<div>` genérico — é o que dá acessibilidade, SEO e comportamento de graça, antes de qualquer CSS ou JS. A apresentação vive em [[03-Dominios/Tecnologia/CSS/index|CSS]]; as APIs de browser vivem em [[03-Dominios/Tecnologia/Plataforma Web/index|Plataforma Web]].
