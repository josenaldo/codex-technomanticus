# Certificação Java OCP

> [!info] Este tronco foi podado
> O conteúdo deste guia virou o **Galho 18 — Certificação OCP**, agora em notas atômicas e publicadas. Comece pelo MOC: [[03-Dominios/Java/Certificação OCP/index|Certificação OCP (Galho 18)]].

O galho cobre as duas provas vigentes — **Java SE 21 (1Z0-830)** e **Java SE 25 (1Z0-831)** —, mapeia os **10 domínios oficiais** às notas dos galhos 1-4 da trilha, e traz as pegadinhas clássicas, o formato da prova e a estratégia de estudo e revisão.
